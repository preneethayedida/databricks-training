# Week 2 - Day 4  
# REGEX Foundations in SQL

## Overview

This module covers the foundational concepts of Regular Expressions (REGEX) in SQL.

The session focuses on:
- extracting digits
- extracting alphabets
- start and end pattern matching
- continuous character extraction
- email parsing
- regex reserved characters
- email validation patterns

These concepts are essential for data cleaning, validation, parsing, and transformation in real-world data engineering tasks.
