# Week 2 - Day 7

## 📝 Overview

Day 7 focused on learning and practicing advanced String Functions in MySQL using employee-based datasets.

The session covered substring searching, string replacement, reversing text, string padding, NULL handling, and advanced string transformations.

These functions are commonly used in real-world data cleaning, formatting, and preprocessing tasks in Data Engineering.
