# Week 2 - Day 1  
# NULL Functions in SQL

## Overview
This module focuses on handling NULL values in SQL using different NULL-related functions and conditions.  
The exercises are designed using real-world datasets containing incomplete or missing values.

Understanding NULL handling is essential for writing production-level SQL queries and performing accurate data analysis.

---

# Objectives

- Understand NULL behavior in SQL
- Learn NULL filtering techniques
- Practice IS NULL and IS NOT NULL
- Use COALESCE for fallback values
- Use NULLIF for conditional NULL conversion
- Handle NULLs in calculations
- Build real-time business logic using NULL functions
