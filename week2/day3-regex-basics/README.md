# Week 2 - Day 3  
# REGEX Functions in SQL

## Overview

This module focuses on Regular Expressions (REGEX) in SQL for pattern extraction and text manipulation.

The exercises are designed using regex-rich datasets containing:
- employee IDs
- country codes
- emails
- phone numbers
- alphanumeric values

These practice problems help build strong pattern matching and string extraction skills commonly used in real-world data engineering tasks.

---

# Objectives

- Understand REGEXP pattern matching
- Extract numeric and alphabetic patterns
- Work with email parsing
- Handle phone number extraction
- Perform substring extraction using REGEX
- Build regex-based SQL logic
