# Week 2 - Day 2  
# Number Manipulation Functions in SQL

## Overview

This module focuses on various numeric and mathematical functions available in MySQL.  
These functions are commonly used for calculations, salary processing, reporting, analytics, and real-time business operations.

The practice queries are designed using employee salary datasets with decimal values and NULL handling scenarios.

---

# Objectives

- Understand numeric functions in MySQL
- Perform rounding and decimal operations
- Apply mathematical calculations
- Work with salary and bonus analysis
- Handle formatted numeric outputs
- Practice real-time numeric operations

---

# Topics Covered

## Basic Numeric Functions
- ABS()
- ROUND()
- CEIL()
- FLOOR()
- TRUNCATE()

## Mathematical Functions
- MOD()
- POWER()
- SQRT()
- SIGN()
- RAND()

## Advanced Number Functions
- FORMAT()
- GREATEST()
- LEAST()
