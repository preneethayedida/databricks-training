# Week 2 - Day 6

## 📝 Overview

Day 6 focused on learning and practicing basic String Functions in MySQL using employee-based datasets.

The session covered string length functions, case conversion, trimming spaces, concatenation, and substring extraction techniques.

These functions are essential for cleaning, formatting, and transforming textual data in SQL.

- Handle spaces and formatting
- Improve SQL data cleaning skills
