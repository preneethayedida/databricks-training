# Week 3 - Day 1

## 📝 Overview

Day 1 focused on learning and practicing Window Functions in MySQL using employee datasets.

The session covered:
- ROW_NUMBER()
- RANK()
- PARTITION BY
- ORDER BY in Window Functions

These concepts are important for ranking, sequencing, analytical reporting, and real-world Data Engineering operations.
