# Week 1 - Day 6

## 📝 Overview

Day 6 focused on learning and practicing Date & Timestamp functions in MySQL using real-world order management scenarios.

The session covered extracting date parts, formatting dates, performing date arithmetic, identifying weekends and weekdays, calculating date differences, and implementing financial year logic.

This practice helped in understanding how SQL handles date and time data in enterprise applications.

---

# 🎯 Objectives

- Understand DATE & TIMESTAMP data types
- Practice date extraction functions
- Learn date arithmetic operations
- Work with formatting functions
- Practice business use cases using dates
- Improve SQL date manipulation skills

---

# 📚 Topics Covered

- CURDATE(), NOW(), CURRENT_TIMESTAMP
- YEAR(), MONTH(), DAY()
- EXTRACT()
- MONTHNAME(), DAYNAME()
- WEEKDAY(), DAYOFWEEK()
- DATE_ADD(), DATE_SUB()
- DATEDIFF(), TIMESTAMPDIFF()
- LAST_DAY()
- DATE_FORMAT()
- STR_TO_DATE()
- Financial Year Logic
- Real-Time Business Queries
