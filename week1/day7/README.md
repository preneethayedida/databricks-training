# Week 1 - Day 7

## 📝 Overview

Day 7 focused on learning and practicing SQL JOIN operations using multiple related tables such as employees, departments, and projects.

The session covered INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN, and SELF JOIN concepts through real-world employee management scenarios.

This practice helped in understanding how relational databases combine data from multiple tables.
